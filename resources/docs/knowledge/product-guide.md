# 产品使用指南

## 一、产品简介

Mneme-rag 是一个基于知识库的 RAG 智能问答助手，支持深度思考与来源引用。它可以将企业内部的文档、手册与 FAQ 转化为可检索的知识库，并通过大模型给出带引用来源的回答。

## 二、快速开始

1. **注册账号**：打开登录页，点击「注册」，填写用户名与密码即可创建账号。
2. **创建知识库**：登录后进入「知识库」页面，点击「新建知识库」，填写名称与向量集合名。Embedding 模型不指定时使用系统默认模型。
3. **上传文档**：进入知识库文档页，点击「上传文档」，支持 Markdown、TXT、CSV、Excel、图片等格式，单文件上限 50MB。
4. **等待分块**：上传后系统自动解析并分块，同时生成向量索引。分块完成后即可开始问答。

## 三、发起提问

- 在「对话」页输入问题，按 Enter 发送。
- 开启「深度思考」可获得更充分的推理过程。
- 回答下方会展示引用来源（来源文档与片段），可点击跳转查看原文。

## 四、管理功能

- **仪表盘**：查看用户、会话、消息数量与问答性能指标。
- **链路追踪**：查看每次问答的节点耗时与成功状态。
- **系统设置**：查看编排模式、上传限制、RAG 检索配置与 AI 模型组。

## 五、常见配置说明

- 知识库按「向量集合」隔离数据，同一集合内的文档共同参与检索。
- 上传 URL 文档可配置定时刷新，保持知识库内容最新。
