# 常见问题 FAQ

## 账号相关

**Q1：忘记密码怎么办？**
在登录页点击「忘记密码」，通过注册邮箱接收重置链接，点击后设置新密码。

**Q2：如何修改自己的密码？**
登录后进入「系统设置 → 账号安全」，输入原密码与新密码即可修改。

**Q3：普通用户能创建知识库吗？**
可以。所有登录用户均可创建自己的知识库；只有管理员能管理用户与系统全局配置。

## 知识库与文档

**Q4：支持哪些文件格式？**
支持 Markdown、TXT、CSV、Excel（xls/xlsx）、图片（png/jpg/jpeg/svg）。PDF 需接入 MinerU 服务后方可解析。

**Q5：上传文件有大小限制吗？**
单文件不超过 50MB，单次请求不超过 100MB。

**Q6：文档分块需要多久？**
取决于文档大小。普通 Markdown 文档通常在数秒内完成解析、分块与向量化。

**Q7：如何让知识库内容保持最新？**
为 URL 来源的文档开启「定时刷新」，系统会按配置的 Cron 周期重新抓取。

## 问答与检索

**Q8：为什么回答显示「未检索到与问题相关的文档内容」？**
表示当前检索范围内没有与问题相关的知识片段。请确认知识库已上传文档并完成分块，或调整提问关键词。

**Q9：回答下方的来源引用如何工作？**
系统检索命中的文档片段会作为引用展示，并支持跳转到原文查看上下文。

**Q10：深度思考模式有什么不同？**
深度思考会使用更强的模型档位，输出更充分的推理过程，但响应耗时更长。
