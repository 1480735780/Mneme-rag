# evaluation — AI 评估

检索与生成质量的可量化评估模块：定义指标、组织数据集、运行基准测试，为 RAG 调优提供数据依据。

## 功能说明

- **metrics.py**：评估指标实现（检索命中率、MRR、NDCG、忠实度等）；
- **benchmark.py**：基准测试运行器（加载数据集 → 调用被测链路 → 计算指标 → 输出报告）；
- **datasets/**：评估数据集（问答对、预期文档、chunk 语料等）。

## 与其他模块的关系

```
benchmark.py ──► rag/（被测检索链路） + core/llm（被测生成链路）
benchmark.py ──► datasets/（输入） + storage/（结果落盘）
scripts/evaluate.py ──► benchmark.py（命令行入口）
```

- **依赖**：`rag/`、`core/llm`、`storage/`、`common/`；
- **被依赖**：`scripts/evaluate.py`、CI 质量门禁（可选）。

## 使用说明与注意事项

1. **数据集规范**：每个数据集建议包含固定 schema（问题、参考文档、预期片段、可选参考答案），便于指标复用；
2. **可复现性**：基准测试应固定随机种子与模型参数（temperature 等），保证结果可比；
3. **指标口径**：检索指标在 `retriever` 层计算，生成指标（忠实度等）依赖 LLM 评判，需明确评判模型与提示词；
4. 评估结果建议输出结构化报告（JSON/Markdown），便于纳入 `docs/` 与版本对比。
