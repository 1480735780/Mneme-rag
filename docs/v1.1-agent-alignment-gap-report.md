## 3 检索质量增强

### 3.1 EvidenceGatePostProcessor（证据相关性闸门）✅ 已交付（2026-08-29）

**ragent-new 文件**：rag/core/retrieval/postprocessor/EvidenceGatePostProcessor.java

**mneme-rag 现状**：~~缺失~~ **已实现** `rag/retrieval/postprocessor/evidence_gate.py`，处理链 v2 完整形态 Dedup(1) → Fusion(5) → Rerank(10) → EvidenceGate(15) → MetadataEnrichment(20)。

**实施时发现并同批修复的关联缺口**：RerankPostProcessor / RoutingRerankService 代码虽在但**从未接入生产装配**（wiring 处理链无 Rerank、闸门硬编码 `rerank_enabled=False`，本节原「RAG 检索管线基本对齐」口径在该点上不成立）。已补齐：
- `app/wiring.py`：`_build_rerank_service`（对称 embedding 装配，占位符 key 跳过）+ `_get_shared_rerank` 懒缓存 + 注入槽；`rerank_active` 同传闸门，闸门开而精排未挂 fail-fast（有测试锁定）。
- `rag/retrieval/config.py`：`RerankProperties`（env `RAGENT_RERANK_ENABLED`）。
- `rerank.py`：移植 Java 两段校准日志（精排分布 + 通道归因/图谱存活率，复用 ChannelAttribution）。
- `bailian_rerank.py`：补位/未出分候选压 0 沉底（`_unscored`，对齐 Java），消除 RRF 名次分与精排分混尺。
- **有意默认值偏离**：Java 默认 `rerank.enabled=true` + `min-rerank-score=0.2`；Python 默认全关（无 `SILICONFLOW_API_KEY` 时精排空转）。激活：`SILICONFLOW_API_KEY` + `RAGENT_RERANK_ENABLED=on` + `RAGENT_SEARCH_EVIDENCE_MIN_RERANK_SCORE=0.2`。

原功能规格（已按此实现）：

    位置：Rerank（order=10）之后、MetadataEnrichment（order=20）之前，order=15
    逻辑：
      1. 取整批 chunks 中最高的 rerank_score
      2. 若 max_score < min_rerank_score（默认 0.2），整批丢弃
      3. 若无精排分可读，降级放行 + warn 日志
    启动校验：
      - min_rerank_score > 0 且 rerank_enabled=false，启动报错
    配置：
      rag.search.evidence.min-rerank-score: 0.2  （0 = 关闭）

### 3.2 KnowledgeSearchFacade（RAG-as-Tool 门面）✅ 已交付（2026-08-29）

**ragent-new 文件**：rag/service/KnowledgeSearchFacade.java

**mneme-rag 现状**：~~缺失~~ **已实现** `rag/service/knowledge_facade.py`，agent_pipeline 的 knowledge_search 工具已接入（未注入门面时保留裸检索兜底，半装配防护）。

**交付要点**：
- 管线：`rewrite_with_split(近期历史)` → `intent_resolver.resolve` + KB-only 过滤 → `detect_ambiguity`（命中澄清短路返回）→ 多通道检索（单子问题失败降级为空）→ `strip_doc_id_anchors` 抹内部锚点 → `build_structured_messages` + LLM 合成（temperature=0 / topP=1 / thinking=False，历史不进合成阶段）。
- `rag/source/citation.py` 补 `strip_doc_id_anchors`（对齐 Java 同名 API，复用 enrich 空来源路径）。
- 零意图子问题照走（不在此拦截，作用域判定只有 ScopeResolver 一份）；MCP/SYSTEM 意图剔除。
- `core/pipeline/agent_pipeline.py`：`knowledge_facade` 注入槽；本 run 近期历史（2 轮 4 条，对齐 Java REWRITE_CONTEXT_TURNS）经 ContextVar 传入工具层——Task 隔离，共享实例不串会话。
- `app/wiring.py`：`_build_knowledge_facade` 从 engine 提取 9 项组件装配（与 chat 链路共享同一批实例）；组件残缺 → 不接门面、agent_service 照常装配。

原功能规格（已按此实现）：

    入口：search(query, recent_history) -> str
    管线：rewrite -> intent resolve（KB-only 过滤）-> ambiguity guidance -> multi-channel retrieve -> answer synthesis
    关键行为：
      - stripDocIdAnchors()：内部 docId 不泄露给 Agent
      - 零意图子问题照走，由 ScopeResolver 回落全局检索
      - 近期轮次只给改写做指代消解，合成阶段不带历史

## 4 数据库变更

### 4.1 新增 3 张表

在 storage/database/schema.py 中新增以下表定义（对应 ragent-new resources/database/upgrades/v1.1.0/260812_agent_engine.sql）：

    -- t_agent_conversation: Agent 会话列表
    CREATE TABLE IF NOT EXISTS t_agent_conversation (
        id              VARCHAR(20) NOT NULL PRIMARY KEY,
        conversation_id VARCHAR(20) NOT NULL,
        user_id         VARCHAR(20) NOT NULL,
        title           VARCHAR(128) NOT NULL,
        last_time       TIMESTAMP,
        create_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
        update_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
        deleted         SMALLINT DEFAULT 0
    );
    CREATE UNIQUE INDEX IF NOT EXISTS uk_agent_conversation_user
        ON t_agent_conversation (conversation_id, user_id) WHERE deleted = 0;
    CREATE INDEX IF NOT EXISTS idx_agent_conv_user_time
        ON t_agent_conversation (user_id, last_time);

    -- t_agent_message: Agent 消息记录（含 thinking_content + blocks JSONB 轨迹）
    CREATE TABLE IF NOT EXISTS t_agent_message (
        id                  VARCHAR(20) NOT NULL PRIMARY KEY,
        conversation_id     VARCHAR(20) NOT NULL,
        user_id             VARCHAR(20) NOT NULL,
        role                VARCHAR(16) NOT NULL,
        content             TEXT,
        thinking_content    TEXT,
        blocks              JSONB,
        reply_to_message_id VARCHAR(20),
        message_status      VARCHAR(16) NOT NULL DEFAULT 'NORMAL',
        create_time         TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
        update_time         TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
        deleted             SMALLINT DEFAULT 0
    );
    CREATE INDEX IF NOT EXISTS idx_agent_msg_conv
        ON t_agent_message (conversation_id, user_id, create_time);

    -- t_agent_state: AgentScope 状态存储
    CREATE TABLE IF NOT EXISTS t_agent_state (
        user_id     VARCHAR(64) NOT NULL,
        session_id  VARCHAR(64) NOT NULL,
        state_key   VARCHAR(64) NOT NULL,
        payload     JSONB,
        create_time TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
        update_time TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
        PRIMARY KEY (user_id, session_id, state_key)
    );
